To start Tezos password recovery, you must:

1. Install John the Ripper and GPU drivers on [Windows](__/install/windows/), [macOS](__/install/macos/), and [Linux](__/install/linux/)

1. [Generate a Tezos password `hash` file](__/create-hash/) that John the Ripper uses for processing, and

1. [Start John the Ripper](__/recover/) using one or more recovery strategies.

We recommend you [view the topics](__/overview/recovery-chances/) in this section before starting.
